# 🎡 ルーレット

名前を入力して回すだけのシンプルな抽選ルーレットです。

▶ https://tachi-k.github.io/Roulette/

---

## 特徴

- 最大45名まで対応
- 回転時間の調整可能
- 回転中BGM付き
- 当選演出あり
- ブラウザだけで動作
- インストール不要

---

## 使い方

1. `index.html` をブラウザで開く
2. 名前を改行区切りで入力
3. 「回す！」ボタンで抽選

---

## ファイル構成

- `index.html` - メインアプリ
- `tin-can-carnival.mp3` - 回転中BGM（Created with Suno AI）
- `brass-verdict.mp3` - 当選時BGM（Created with Suno AI）
